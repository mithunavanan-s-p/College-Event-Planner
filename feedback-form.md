# Event Feedback Form

Please collect feedback after the event. Responses may be collected using a paper form or a college-approved online form.

1. How would you rate the overall event? (Excellent / Good / Average / Needs improvement)
2. Was the event well organized? (Yes / Partly / No)
3. Which activity did you like most?
4. Was the schedule convenient? (Yes / No)
5. How would you rate the venue and facilities? (Excellent / Good / Average / Needs improvement)
6. What did you learn or enjoy?
7. What should we improve next time?
8. Any other suggestions? (Optional)
