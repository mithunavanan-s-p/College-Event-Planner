# College Event Planner

A simple GitHub repository template to plan, organize, document, and review a college event.

## Project purpose
This repository helps students keep all event information in one place:
- Event details and schedule
- Activities and programme plan
- Budget and expense tracking
- Team responsibilities
- Feedback and post-event review

## How to use this repository
1. Update `docs/event-details.md` with your event information.
2. Add each programme item to `docs/activities.md`.
3. Record expected and actual expenses in `templates/budget.csv`.
4. Assign team members and deadlines in `templates/team-responsibilities.csv`.
5. Collect feedback using `docs/feedback-form.md`.
6. After the event, add the results and lessons learned to `docs/post-event-review.md`.

## Suggested GitHub workflow
- Create an Issue for each major task.
- Assign each Issue to the responsible student.
- Use labels such as `Planning`, `Venue`, `Finance`, `Publicity`, and `Completed`.
- Upload posters, permission letters, and photos to suitable folders (only with permission).
- Update this README when the event plan changes.
